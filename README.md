# Danyal Tanveer — Portfolio

A personal portfolio for a software and AI engineer, built with Next.js 15, React 19, TypeScript, GSAP, and Tailwind CSS 4.

## Experience

The 2026 redesign uses electric blue, yellow, and ink with an editorial collage hero. The supplied portrait appears on an interactive hanging engineer pass with free two-dimensional dragging, a flexible strap, momentum, spring return, and arrow-key controls. The page flows through the hero, About and Education, selected work, Skills, an interactive engineering toolkit, research, smaller experiments, and contact.

- Six featured projects with category filters and accessible native detail dialogs.
- A searchable Skills section with 63 résumé-based skills across eight disciplines.
- Three interactive engineering workflows with selectable stages.
- Colorful Playground folders with animated opening, keyboard controls, and framed project previews.
- Staggered Skills reveals and interactive category icons.
- GSAP entrance animations, scroll reveals, a hanging ID card, and a progress indicator.
- Responsive navigation, keyboard controls, reduced-motion support, and a motion toggle.
- Updated graduate, internship, research, certification, and résumé content.
- Validated contact API using Resend, with rate limiting and escaped email HTML.

## Run locally

```sh
npm install
npm run dev
```

Open http://localhost:3000. For another port, run `npm run dev -- --port 3010`.

```sh
npm run build
npm run start
npm run lint
npx tsc --noEmit
```

Copy `.env.example` to `.env.local` and configure Resend for contact delivery. Set `NEXT_PUBLIC_SITE_URL` to the deployed canonical URL. The direct email link remains available if delivery is unavailable.

## Project visuals

`public/projects/feastly-ui.png`, `archive-ui.png`, `shopora-ui.png`, `orbit-ui.png`, and `games-ui.png` are generated interface mockups based on documented project features. They are explicitly labeled in the portfolio and are not presented as screenshots of deployed products. TRAK, Restaurant OS, and the other existing project visuals use supplied assets.

The portrait is the user's supplied transparent PNG. Original project assets, résumés, and design references are retained for future updates. Unused components from the previous design have been removed.

## Generated folders

`.next/` is generated by Next.js for development and production builds; it is ignored by Git and can be regenerated with `npm run dev` or `npm run build`. Temporary `.next-*` preview folders have been removed. `node_modules/` contains installed dependencies and is required to run the project locally.

The `Images`, `Resumes`, `Snapshots of projects`, `Readme of my projects`, and `Website ideas` folders are original source/reference materials, so they are kept. `.agents/` contains project tooling instructions.

`src/app/typography.css` controls readable text sizes, tablet navigation, and full-width Education and Internship layouts.
