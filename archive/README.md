# Source Material Archive

This folder contains material that is **not shipped by the portfolio**, but can still support future content updates.

## What belongs here

- `design/` — alternate branding, portrait concepts, and visual references.
- `profile/` — editable résumé sources and original credential files.
- `project-sources/notes/` — project documentation used to write portfolio copy.
- `project-sources/screenshots/` — raw or alternate screenshots that may support future case studies.
- `project-sources/research-visuals/` — research figures that are not currently displayed.

## Production boundary

Only optimized assets referenced by the application belong in `public/`. If an archived image is used again, copy an optimized version into an appropriate `public/` subfolder and reference it from the code. Do not link the application directly to this archive.

## Retention rules

- Keep editable source documents, original credentials, raw project evidence, and useful design references.
- Remove byte-for-byte duplicates when an authoritative copy already exists elsewhere.
- Remove obsolete generated mockups after a real project screenshot replaces them.
- Do not place build output, dependencies, temporary captures, or secrets here.
